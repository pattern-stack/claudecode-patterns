# Add UserPromptSubmit nag hook surfacing `/sdlc:setup` when sdlc.yml is missing

## Goal

Surface a `<system-reminder>` to the assistant on every UserPromptSubmit when `.claude/sdlc.yml` is missing, nudging it to suggest `/sdlc:setup`. Quiet on configured projects.

## Approach

Plugin-shipped Node hook at `plugin/hooks/check-config.mjs`. Reads `${CLAUDE_PROJECT_DIR}` (set by Claude Code), checks `.claude/sdlc.yml` existence. If missing, emits the hook protocol JSON with `hookSpecificOutput.additionalContext` carrying the reminder.

Wired into `plugin.json` `components.hooks.UserPromptSubmit` alongside the existing emit.mjs fan-out.

## File-level plan

### Create

| Path | Purpose |
|---|---|
| `plugin/hooks/check-config.mjs` | The hook script. Returns hook-protocol JSON with additionalContext on missing sdlc.yml. |

### Modify

| Path | Change |
|---|---|
| `plugin/.claude-plugin/plugin.json` | Append a second UserPromptSubmit hook entry calling check-config.mjs (synchronous; timeout 3s). |

## Tests

- Manual: in a fresh tmpdir without `.claude/sdlc.yml`, send a prompt; confirm assistant context receives the system-reminder.
- Manual: after `/sdlc:setup` writes sdlc.yml, send another prompt; confirm no reminder.

## Out of scope

- Stderr fallback path (deferred — only relevant if Claude Code drops `additionalContext` support, which it currently has).
- Throttling (one reminder per prompt while sdlc.yml absent — fine).
- Configurable reminder text (single message; v2 if requested).
