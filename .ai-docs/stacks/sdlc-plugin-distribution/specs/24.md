# Add `/sdlc:setup` slash command (AskUserQuestion-driven onboarding)

## Goal

Ship `/sdlc:setup` — the post-install onboarding flow that scaffolds a fresh project's `.claude/sdlc.yml` + Justfile module + symlink to the plugin's `sdlc.justfile`. Renamed from `/sdlc:init` to avoid collision with native `/init` (CLAUDE.md generator).

## Approach

Slash command in `plugin/commands/setup.md` (agent-flavored: prompt the main agent to drive an interactive AskUserQuestion flow). One conversational pass:

1. Detect existing `.claude/sdlc.yml`. If present, offer reconfigure / quit (default quit; reconfigure backs up old).
2. AskUserQuestion × 3 enums: `language` (typescript/python/go/other), `quality_profile` (strict/fast), `task_management` (linear/github/jira).
3. Free-text prompt for `team_key` (validate `^[A-Z][A-Z0-9]{1,9}$` for Linear-shape; harmless under github).
4. Render `.claude/sdlc.yml` from the example template, substituting answers.
5. Create `.claude/sdlc.justfile` symlink → `${CLAUDE_PLUGIN_DIR}/sdlc.justfile`. Halt with clear error if `${CLAUDE_PLUGIN_DIR}` is unavailable.
6. Detect Justfile: none / exists. If none, create with `mod sdlc '.claude/sdlc.justfile'`. If exists, AskUserQuestion: add `mod` (recommended), `import` (top-level recipes; collision-checked), or skip.
7. Run `bash ${CLAUDE_PLUGIN_DIR}/scripts/bootstrap-tracker.sh` if `task_management: github` (best-effort; warn on failure but continue).
8. Run `just sdlc::verify`. If `just` not installed, warn and skip; do not fail.
9. Print next-steps with two items:
   - Gate-mode override layers (one line, always).
   - `/sdlc:link-project <project-url>` pointer (only if `task_management: github`).

Setup does **not** ask about gate mode (defaults to strict via `sdlc.example.yml`'s `gate1_default: strict`). Setup does **not** run `/sdlc:link-project` itself — opt-in post-setup.

## Tests

- Manual smoke in a fresh tmpdir:
  1. `mkdir /tmp/test-fresh && cd /tmp/test-fresh && git init`
  2. Set `CLAUDE_PLUGIN_DIR=/path/to/plugin`.
  3. Invoke `/sdlc:setup`.
  4. Confirm `.claude/sdlc.yml` valid + `.claude/sdlc.justfile` resolves + Justfile created/updated + verifiers pass.
- Reconfigure path: re-run `/sdlc:setup` on a project with existing sdlc.yml; confirm backup written + reconfigure works.

## Out of scope

- TUI/wizard. AskUserQuestion IS the v1 wizard.
- Asking about gate mode (defaults strict; override layers documented in next-steps output).
- Running `/sdlc:link-project` automatically (opt-in post-setup; PR 5 ships the command).
- `extends:` sdlc.yml layering (v2).
